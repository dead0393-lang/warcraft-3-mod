Warcraft III 1.29.2 — камера (ACC) + FPSUnlocker
================================================

Нужна версия игры 1.29.2 (как Legacy TFT 1.29).
В папке с Warcraft III.exe не должно быть отдельного Game.dll.

Установка
---------
1. Закройте игру.
2. Запустите install.bat и укажите папку с игрой
   (или просто перетащите папку игры на install.bat).
3. Если батник недоступен, скопируйте вручную в папку игры:

     ACC.mix
     FPSUnlocker.mix
     mss32.dll
     mss32_miles.dll

   Если у вас ещё оригинальный звуковой Mss32.dll (около 350 КБ),
   сначала переименуйте его в mss32_miles.dll, потом копируйте наш mss32.dll.
   Файл mss32_miles.dll удалять нельзя — без него не будет звука.

4. Запустите Warcraft III.exe.

Камера (ACC)
------------
В чате:
  /distance N     дистанция (по умолчанию 1650)
  /aoa N          угол атаки (300)
  /farz N         дальность (5000)
  /fov N          поле зрения (70)
  /roll N
  /rotation N
  /zoffset N
  /default        сброс
  /smooth on
  /smooth off

Клавиши:
  F7              цикл камеры вкл/выкл (по умолчанию включён, каждые 0.5 с)
  Numpad + / -    дистанция ±100
  Numpad *        дистанция 1650

Исходники
---------
src\acc.cpp           камера
src\mss32_proxy.cpp   загрузчик mix через mss32.dll
src\build.bat         сборка (нужен Visual Studio, x86)

Сборка из src\ копирует ACC.mix и mss32.dll в папку на уровень выше.
Для своей игры правьте пути в src\build.bat.
